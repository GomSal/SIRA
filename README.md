# SIRA · Rama `General-Documentation`

Rama dedicada exclusivamente a centralizar las **guías paso a paso de construcción y manuales de uso finales** del proyecto **SIRA** (Equipo 10 · Universidad EAFIT), organizados por disciplina.

## Estructura de Carpetas (Preparada)

```text
General-Documentation/
├── README.md                  # Esta portada
├── Big Data/                  # Aquí se cargarán las guías paso a paso y manuales de Big Data / AWS
└── Machine Learning/          # Aquí se cargarán las guías paso a paso y manuales de Machine Learning
```

> *(Las carpetas están creadas e inicializadas vacías con `.gitkeep`, listas para recibir los documentos finales sin mezclar código).*
